The Norton spacing system uses a scale based on 4px increments to create consistent spacing within and between components. Use the scale to establish hierarchy, group related elements, and create clear, readable layouts.

## Design Tokens

The Norton spacing system uses a shared scale of system tokens. Token names follow the pattern: `spacing-{step}`, where the step represents a multiple of the 4px base unit. For example, `spacing-4` corresponds to 16px, or 1rem at a 16px root font size.

## Usage

Choose spacing based on the relationship between elements. Smaller values keep related content together and build components; larger values separate groups, sections, and overall product layout.

### Within components

Use smaller spacing values for closely related elements, such as an icon and label. Follow existing component specifications for internal padding and gaps.

{/* Image placeholder: spacing within components */}

### Between components

Use moderate spacing values to separate components within the same group, such as form fields, cards, or stacked content.

### Between sections

Use larger spacing values to distinguish major sections and give page and product layouts room to breathe.

### Hierarchy

Use spacing to create visual hierarchy between content and elements. Keep related components close together and use larger spacing or gaps between groups or sections. Consistent spacing helps users scan the page and understand its structure, especially when products become complex or dense.

## Accessibility

Spacing helps users distinguish related content, identify separate sections, and interact with controls. While spacing between controls supports usability, designs should always include adequate target sizes.

- Keep related elements close together and use more space between separate groups.
- Leave enough space between interactive elements to reduce accidental selections.
- Allow layouts to adapt when text wraps, users zoom, or screen sizes change.
- Avoid fixed heights that clip content when text size or text spacing increases.

### Target size

Aim for clickable or tappable areas of at least 44 × 44 CSS pixels to make controls easier to use. WCAG 2.2 Level AA requires at least 24 × 24 CSS pixels, unless a defined exception applies. Use padding to increase the target area without enlarging the visible icon or label.
